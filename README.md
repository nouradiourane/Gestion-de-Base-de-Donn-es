#  Projet Exploration Spatiale (SQL)

##  Présentation
Ce projet, daté de décembre 2023, implémente une base de données relationnelle complète pour la gestion des missions spatiales internationales et des spationautes.

##  Structure des Données
Le schéma repose sur 4 tables interconnectées :
- **pays** : Démographie et superficie.
- **spationaute** : Biographies et nationalités.
- **mission** : Historique des vols spatiaux.
- **participe** : Rôles spécifiques (Commandant, Ingénieur, etc.) par mission.
